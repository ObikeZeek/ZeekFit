# ZeekFit v2

ZeekFit is a private, mobile-first workout PWA built from the original weekly bodyweight checklist.

## What's new in v2

- Guided A/B/C workouts with round and exercise progression.
- Animated exercise avatar for every movement.
- Exercise-specific form/coaching cues.
- Timers for timed movements and optional timers for any exercise.
- Voice coaching through the browser's built-in speech synthesis.
- Automatic progression: after repeated successful sessions, targets gradually increase.
- XP and level system.
- Weekly completion tracking.
- Streak tracking.
- Session history.
- Body-weight check-in.
- Weekly energy rating.
- Audio toggle.
- Local-only data storage.
- Offline-capable PWA shell.
- No account, ads, social feed, or server/database.

## Original regimen preserved

### Weekly schedule
- Monday — Workout A
- Tuesday — Workout B
- Wednesday — Rest
- Thursday — Workout A
- Friday — Rest
- Saturday — Workout C
- Sunday — Rest

### Daily warm-up
- Jumping jacks — 30 sec
- Arm circles — 20 forward / 20 backward
- Bodyweight squats — 10 reps
- Torso twists — 20 reps
- March in place — 1 min

### Workout A — Upper Body + Core
2 rounds
- Incline / knee push-ups — 8–12 reps
- Shoulder taps — 10 per side
- Plank — 20–30 sec
- Mountain climbers — 20–30 sec
- Rest 60 sec between rounds

### Workout B — Lower Body + Cardio
2 rounds
- Squats — 12–15 reps
- Reverse lunges — 8 per leg
- Glute bridges — 12–15 reps
- Wall sit — 20–40 sec
- Rest 60 sec between rounds

### Workout C — Full Body + Stamina
3 rounds
- March in place / high knees — 1 min
- Push-ups — 8–12 reps
- Squats — 12 reps
- Plank — 20–30 sec
- Rest 60 sec between rounds

### Cool-down
- Hamstring stretch — 30 sec per leg
- Quad stretch — 30 sec per leg
- Child's pose — 1 min
- Shoulder stretch — 30 sec per side

## Install on iPhone

For the full PWA "Add to Home Screen" experience, the folder should be hosted on an HTTPS static site.

1. Put the four files on a static HTTPS host (GitHub Pages is one option).
2. Open the site in Safari.
3. Tap Share.
4. Tap "Add to Home Screen".
5. Launch ZeekFit from the Home Screen.

## Important note

The avatar is a visual movement guide, not a medical or professional fitness assessment. Stop an exercise if it causes sharp pain, dizziness, or unusual symptoms.
